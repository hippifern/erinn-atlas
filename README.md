# The Erínn Atlas

An immersive interactive fantasy atlas experience built with React, Next.js, React Three Fiber, and Three.js.

The project combines a cinematic 3D medieval inn scene with a living fantasy world map inspired by Celtic mythology, worldbuilding, and historical atlases.

Users can explore locations, discover lore, and navigate through different eras of the world using an interactive timeline system.

---

## Features

- Atmospheric 3D medieval inn scene
- Cinematic camera movement and transitions
- Interactive fantasy world map
- Zoom and pan navigation
- Clickable locations and lore panels
- Timeline slider with historical state changes
- Motion-rich UI and environmental effects
- Ambient lighting, fog, particles, and atmosphere

---

## Experience Flow

### 1. Medieval Inn Scene

Users begin inside a candle-lit medieval inn containing several interactive points of interest.

### 2. Cinematic Transition

Selecting the central map table triggers a cinematic transition into the atlas experience.

### 3. Interactive Atlas

Users can:

- explore regions
- zoom and drag across the map
- inspect locations
- discover lore
- move through different historical eras

## Running Locally

Install dependencies:

```bash

```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
